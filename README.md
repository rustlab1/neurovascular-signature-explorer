# Neurovascular Molecular Signatures in Neurodegeneration

Interactive companion to

> Forster PM, Bracko O, Rust R. **Shared and disease-specific human brain
> vascular signatures in Alzheimer's disease, frontotemporal dementia, and
> Huntington's disease.** bioRxiv (2026). doi:[10.64898/2026.07.01.735865](https://doi.org/10.64898/2026.07.01.735865)

a comparative single-nucleus RNA-seq study of human brain vascular and perivascular cells in
Alzheimer's disease (AD), GRN-related frontotemporal dementia (FTD-GRN) and Huntington's disease (HD).

## Sections

- **Atlas & gene UMAPs** - published UMAPs of the non-neuronal atlas (8 cell types), the endothelial
  cells (arterial / capillary / venous zones) and the pericytes (T-peri / M-peri), control and disease
  side by side for each dataset; type a gene to colour all panels by its expression on one shared scale.
- **Gene search** - any gene in the explorer: mean expression per cell type, zone and pericyte subtype
  in control and disease, or the MAST disease-vs-control log2 fold-changes.
- **Cell-type DEGs** - DEG lists per dataset and cell type (padj < 0.05, |log2FC| > 0.25).
- **Cross-disease** - DEG overlap per cell type and direction, the core genes of all eight cell types,
  and the correlation of disease effects in endothelial zones and pericyte subtypes.
- **Pericytes** - M-peri proportions (Fig 3B; the Results-text definition in a note), the pooled-pericyte
  DEG Venn (Fig 3D), the Fig 3C marker panel and subtype DEG lists.
- **Endothelium** - zone proportions (Fig 2B) and zone DEG lists.
- **Pathways** - top terms of the paper's enrichment analyses (Fig 1F/G, Fig 2F, Fig 3G, Supp Fig 3C/D).
- **Signaling** - CellChat network summary, per-pathway information flow, Fig 4D PCA and the curated
  Fig 4A pathway list.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure and styles |
| `app.js` | Client logic and rendering |
| `data.js` | DEG lists, overlaps, convergence, pathways, CellChat summaries (`window.NV`) |
| `umap.js` | Downsampled UMAP coordinates and labels (`window.NV_UMAP`) |
| `expr/index.json` | Gene list and layout of the expression shards |
| `expr/s*.bin` | Per-gene binary records (mean expression and % expressing per group, MAST rows, quantised expression of the UMAP nuclei), fetched on demand |

The gene shards are loaded with `fetch()`, so the site must be served over http(s); for a local
preview run `python3 -m http.server` in this folder and open <http://localhost:8000>.

## Rebuilding the data

All data files are generated by `scripts/19_build_explorer.R` in the analysis code repository
([neurovascular-signature-code](https://github.com/pmforster/neurovascular-signature-code)) from the final Seurat objects (`data/objects/{AD,FTD,HD}_{atlas,endo,peri}.rds`),
the CellChat objects of the main run and the result tables in `results/`. From the code repository root:

```bash
NV_EXPLORER_DIR=../neurovascular-signature-explorer Rscript scripts/19_build_explorer.R
```

Nothing on the site is typed in by hand except labels and descriptions. See the script header for
thresholds, downsampling and the binary format of `expr/`.

## Data notes

- FTD-GRN is labelled `FTD` in the analysis tables.
- Differential expression is disease vs matched control with MAST; a positive log2 fold-change
  means higher expression in disease.
- UMAPs show downsampled nuclei (atlas ~6,000 per dataset; endothelial cells and pericytes up to
  ~4,000 per dataset); means and % expressing are computed on all nuclei.
